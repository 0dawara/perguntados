# Cronograma de Execução - Perguntados

Estimativa de alto nível para a execução e entrega do projeto:

- **Fase 1 (Semana 1-2)**: Criação de protótipos, configuração inicial do Back4App, modelagem das tabelas do banco de dados e adequação do repositório no Github (a partir do projeto Flutter já existente).
- **Fase 2 (Semana 3-4)**: Implementação no Flutter das telas iniciais e de Autenticação (Login/Cadastro), com integração ao Banco de Dados. Inserção manual da massa de dados inicial (perguntas de Matemática, Linguagens, História, etc.) no Back4App.
- **Fase 3 (Semana 5-6)**: Implementação do Core Loop do jogo (Jogar, responder, contar tempo, validar e computar pontuação) e desenvolvimento da tela de Leaderboard (Placar Global).
- **Fase 4 (Semana 7)**: Ajustes de interface de usuário (UI/UX), testes automatizados (se aplicável) e Deploy contínuo final via Vercel.
